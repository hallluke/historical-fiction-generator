# Historical Fiction Title Generator

A humorous, browser-based generator of implausibly plausible historical-fiction bestsellers.

Generate fictional book titles, complete with authors, dramatic taglines, literary reviews and occasional award nominations. Each book is added to an illustrated bookshelf.

## Features

- 130 occupations and 130 locations, producing 16,900 possible title combinations
- Procedurally generated taglines, authors and reviews
- Occasional fictional literary awards and rare winner celebrations
- Illustrated, interactive bookshelf
- Copyable book descriptions
- Customisable generation settings

## Usage

Visit the [live generator](historical-fiction-generator), or download `index.html` and open it in a modern web browser.

No installation, account, server or external dependencies are required.

## Development

Built iteratively with assistance from OpenAI's ChatGPT. Concept, creative direction, content selection and testing were guided by the project creator.
